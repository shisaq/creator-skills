# 账号档案模板

复制成 `账号档案.md`，放在你的选题/素材目录（或它的上级目录），写稿时会自动读到。也可以放在任何地方，然后设置环境变量 `SHORT_VIDEO_PROFILE` 指向它。

档案里**最有用的是最后两节**：定稿范例和改稿记录。规则写得再细，也不如几条真实的"我把这句改成了那句"。

```markdown
# 账号档案：<账号名>

## 定位
- 一句话：<这个账号是干什么的>（例：一个普通上班族折腾 AI 的笔记）
- 观众：<具体是谁，他们关心什么、怕什么>
- 观众为什么关注我：<信任来源：专业？真实？好笑？省事？>

## 口吻
- 像谁在说话：<例：懂行的朋友，不是老师>
- 第一人称：<常用 / 少用>
- 情绪幅度：<克制 / 适中 / 夸张>
- 可以用的：<例：适度自嘲、口语情绪词>
- 不要用的：<例：圈内黑话、"家人们"、满屏感叹号>

## 禁区
- <不能说的话题、不能提的竞品、不能承诺的效果>

## 商业露出（没有就删掉这节）
- 产品/品牌：<名字>
- 规则：<例：每个平台最多提一次，当成选项之一，不写官网和下载>

## 常用互动口径
- <例：你平时会……吗？>

## 定稿范例
（贴 2–3 条你满意的成稿，口播稿或发布文案都行）

## 改稿记录
| 初稿 | 定稿 | 为什么改 |
|---|---|---|
| | | |
```
