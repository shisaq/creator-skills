# 口语化：写给耳朵听

口播稿的读者是耳朵。眼睛可以回看，耳朵不能。所以标准只有一个：**念一遍，顺不顺，听一遍，记不记得住。**

## 念稿检查

写完后逐句"念"一遍（在心里按正常语速过），出现下面任何一种就改：

- 一口气念不完，中间要换气 → 拆成两句
- 念到一半要回头确认主语是谁 → 句子太长或从句嵌套，拆
- 有两个字连在一起念着别扭（"实时时序""这些事实时"）→ 换词
- 听的人分不清的同音词（"期中/期终""全部/全不"）→ 换个说法
- 括号、引号、斜杠、英文缩写串 → 念出来就是一团，改成说得出口的话

## 句子

- 一句话只说一件事。单句**尽量不超过 20 个字**，超过 25 个字一定拆。
- 长短交替。全是短句像电报，全是长句像念报告。三四个短句之后，可以来一个稍长的。
- 主语清楚，少用"其""该""此"这类代词，口语里直接重复名词或用"它""这个"。

## 书面词 → 说话的词

| 书面 | 说出来 |
|---|---|
| 因此、故而 | 所以 |
| 然而、但是却 | 但是、可是、不过 |
| 此外、另外还有 | 还有、再说 |
| 并且、同时 | 而且、还 |
| 若、如若 | 要是、如果 |
| 即、亦即 | 就是 |
| 其（它的） | 它的 |
| 该（这个） | 这个、这 |
| 进行设置/进行操作 | 设置一下 / 弄一下 |
| 予以解决 | 解决掉 |
| 能够 | 能 |
| 是否 | 是不是、有没有 |
| 首先……其次……最后 | 第一步……然后……最后（或者干脆不编号） |
| 综上所述、总而言之 | 删掉 |

## 口语的"呼吸"

真人说话会有一些让节奏更自然的东西，适量保留：
- 设问：「怎么办？很简单。」
- 口头的确认：「对吧」「你看」「说白了」（一条里一两次）
- 自然的停顿感：在要强调的词前面断一下，单独成段

但别过头："那么呢""然后呢就是说"这种真的口水词要删。

## 专业词

- 第一次出现时用一句人话解释：「RAG，说白了就是让 AI 先翻资料再回答。」
- 能不用就不用。观众听不懂的词，每出现一次就流失一批人。
- 英文缩写念出来要顺：给 TTS 用的稿子，必要时注明读法，比如「API（A-P-I）」。

## 给 TTS 用的稿子

- 每段一行，段与段之间空一行，方便配音工具按段断句。
- 数字写成想让它念的样子：「2026 年」可能被念成"两千零二十六年"，需要的话写成「二零二六年」。
- 避免括号、表格、emoji、特殊符号。
