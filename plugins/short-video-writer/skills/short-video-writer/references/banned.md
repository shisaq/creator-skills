# 禁用清单：AI 味与技术腔

`scripts/check.py` 会自动查这里大部分条目。查出来的每一处都要改，改法见右列。

## 一律不用的句式

这些是最容易被一眼认出"AI 写的"的句式。在短视频里**一次都不要出现**：

| 句式 | 怎么改 |
|---|---|
| 不是 A，而是 B | 把 A 和 B 各自写成一个具体事实，前后两句摆出来；或者直接只说 B |
| 不是 A，是 B | 同上 |
| 与其 A，不如 B | 直接说"B 更好"，再给一个理由 |
| 不仅 A，更 B / 不仅 A，还 B | 拆成两句，各说各的 |
| 既 A 又 B | 拆成两句，或只保留更重要的那个 |
| 从 A 到 B（用来显得全面时） | 举一个具体例子代替 |
| 真正的价值/关键/意义在于 | 删掉这半句，直接说那个价值 |
| 这背后反映/折射的是 | 删掉，直接说结论 |
| 这意味着 | 删掉，或换成"所以" |
| 在这个过程中 | 删掉 |
| 对于 XX 来说 | 换成"XX 的话"，或直接以 XX 当主语 |
| 随着 XX 的发展/普及 | 删掉整句铺垫 |
| 值得一提的是 / 不难发现 / 毋庸置疑 | 删掉 |
| 总而言之 / 综上所述 / 总的来说 | 删掉，结尾不做总结 |
| 让我们一起…… | 换成具体的行动邀请 |
| 三连排比（A、B、C 三个并列短语） | 留最重要的一个，或换成一个具体例子 |
| 破折号解释（——） | 一条稿子最多一处，其余改成句号拆开 |

## 少用的技术腔/营销腔

这些词本身没错，但堆在一起就是"报告味"。每条最多出现一次，用了就必须紧跟一个具体场景：

赋能、闭环、抓手、底座、范式、生态、沉淀、链路、颗粒度、打通、一站式、全方位、全链路、深度融合、降本增效、提质增效、助力、维度、场景化、智能化升级、数字化转型、重塑、颠覆、革命性、划时代

## 夸张承诺（直接删）

彻底颠覆、完全替代、百分百、零成本、躺赚、封神、杀疯了、炸裂（除非账号档案明确允许这种风格）

## 写完的终检

把稿子从头念一遍，问自己：
1. 有没有哪句话，换任何一个账号、任何一个话题都能用？——有就删，那是空话。
2. 有没有哪句话在"宣布"一个观点，而没有给出事实？——补事实，或删。
3. 像不像一个真人在跟朋友说话？
