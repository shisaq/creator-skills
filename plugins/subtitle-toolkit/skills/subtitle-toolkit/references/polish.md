# 字幕润色

目标：把语音识别出来的字幕改**对**。错字、同音字、专有名词、明显的漏字多字。讲话人的口气和用词习惯留着，这是他的字幕，不是你的文章。

## 流程

1. **抽取**
   ```bash
   srt_tools.py extract "<字幕>"
   ```
   打印 `序号|文本`，时间码存进旁边的 `.cues.json`。

2. **通读一遍再动手。** 先弄清这段视频在讲什么（产品演示？行业观点？课程？访谈？）、谁在讲、有哪些反复出现的专有名词。很多同音字只有知道语境才判断得了：编程语境里"原代码"是"源代码"，财务语境里"合对"是"核对"。

3. **加载术语表**（见 SKILL.md「术语表」一节），再看 `references/common_asr_errors.md` 里的通用高频错误。

4. **只写改动的条目**到 `<字幕文件名>.edits.txt`（与字幕同目录，文件名是在原文件名后面加 `.edits.txt`）：
   ```
   4|我们打开 GitHub 的仓库页面|专有名词
   11|切到流程图视图|同音字
   27|这个按钮在右上角|漏字
   ```
   格式：`序号|改后的整条文本|类型`。类型用：专有名词 / 同音字 / 漏字 / 多字 / 英文拼写 / 数字 / 标点 / 语气词。
   没改的条目不要写进去——条目越少，越不容易误伤。

5. **生成**
   ```bash
   srt_tools.py apply "<字幕>"
   ```
   输出 `<名>_润色.srt` 和 `<名>_润色明细.md`。时间轴、序号、条数由脚本保证不变。

## 改什么、不改什么

| 改 | 不改 |
|---|---|
| 同音/近音错字、专有名词、英文拼写、数字写法 | 讲话人的口头禅和句式（"那我们来看一下""对吧"） |
| 明显的漏字、重复字（"我们我们"） | 把口语改成书面语 |
| 识别出来的无意义填充音（"呃呃""嗯嗯"连串）可删 | 删掉有语气作用的"好""那""其实" |
| 必要的断句标点（如果原字幕带标点） | 给没有标点的字幕风格硬加标点 |
| 明显的口误且后面没有自我纠正时，按讲话人本意改 | 改写观点、补充原话没说的信息 |

**拿不准就不改**，把它放进汇报的"待确认"里。改错一个专有名词，比留一个错字更糟。

## 汇报格式

```
## 润色完成

**输出**：<名>_润色.srt（明细见 <名>_润色明细.md）
**统计**：共 N 条字幕，修改 M 处（专有名词 a / 同音字 b / 其他 c）

**主要订正**：最多列 10 条有代表性的（完整列表在明细文件里）
**待确认**：拿不准的人名、数字、术语，附序号和时间
**建议加入术语表**：本次发现、以后很可能再遇到的误识别（"识别结果 → 正确写法"），用户同意后可以追加到术语表文件
```
