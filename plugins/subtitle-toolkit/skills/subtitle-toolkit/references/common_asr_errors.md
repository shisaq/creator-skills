# 通用语音识别高频错误

与任何品牌无关、在中文讲解类视频里反复出现的误识别。润色时作为参考：**看语境再改**，表里的词在别的语境下可能是对的。

## 同音 / 近音字

| 常见误识别 | 通常应为 | 出现语境 |
|---|---|---|
| 试图、示图、师图 | 视图 | 软件界面（"列表视图"） |
| 原代码 | 源代码 | 编程 |
| 第三番库 | 第三方库 | 编程 |
| 书记处理 | 数据处理 | 技术 |
| 绘画、汇化 | 会话 | AI 对话、聊天 |
| 深层、深成 | 生成 | AI 生成内容 |
| 耸动 | 手动 | 操作说明 |
| 搭过来 | 拖过来 | 拖拽操作 |
| 新号 | 星号 | 符号 `*` |
| 封号 | 分号 | 符号 `;` |
| 用力 | 用例 | 测试、示例 |
| 次生 | 自身 | "根据自身需要" |
| 去客 | 即可 | 句末 |
| 销率 | 效率 | 通用 |
| 势力 | 示例 | 演示、文档 |
| 留言器、流量器 | 浏览器 | 网页操作 |
| 机分 | 积分 | 会员、计费 |
| 合对 | 核对 | 财务、对账 |
| 带付款、以付款 | 待付款、已付款 | 订单状态 |
| 无人之手 | 无人值守 | 自动化、运维 |
| 偷分、投分 | token | 大模型计费 |
| 多冷的交互 | 多轮交互 | AI 对话 |

## 口音相关

| 常见误识别 | 通常应为 | 说明 |
|---|---|---|
| 介面 | 界面 | 台湾/粤语口音，按大陆用法统一时改 |
| 餐单 | 菜单 | 粤语口音 |
| 登入、帐户 | 登录、账户 | 繁体/台湾用法，面向大陆观众时统一 |
| 著（尝试著） | 着 | 繁简混用 |
