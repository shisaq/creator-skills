# 出镜档案（模板）

复制到 `~/.config/creator-skills/profiles/<名字>.md` 后填写。这是你的私人数据，别提交到任何公开仓库。
short-video-writer 也能把它当"账号档案"用。

```markdown
# 出镜档案 — <名字>

## 是谁
- 名字 / 常用称呼：
- 身份（可在文案里提到的程度）：例如"个人号，弱化公司头衔"
- 账号：视频号 / 抖音 / YouTube 名称

## 文案口吻
- 人称：第一人称（"我觉得""今天打球时想到"）/ 第三人称介绍
- 语气：例如"平实、有观点，不喊口号"
- 禁区：例如"不提公司产品""不写头衔"

## 视觉
- 配色（a / b / accent）：例如 #8BD400 / #FF3B4E / #FFC72C，或"按每条视频的主题定"
- 字体：例如"阿里巴巴普惠体（本机已装）"
- 背景：court / plain

## 声音
- BGM 目录：例如 ~/Music/AIGC（偏好 lo-fi、轻科技感；音量 0.13）
- 音效：开 / 关

## 转写
- 常用专名（每次都加进 --terms）：
- FunASR 服务：SELFMEDIA_FUNASR_URL=…（没有就留空）

## 改稿记录（每次用户反馈后追加一行）
- 2026-xx-xx：……
```
