# 包装规矩（每一条都来自真实返工）

脚本已经把能自动化的做掉了；剩下的是写 spec 和检查截图时要盯的。

| 规矩 | 为什么 | 怎么做到 |
|---|---|---|
| 字幕不压嘴 | 自拍口播脸很大，常规字幕位置（画面下 1/3）正好在嘴上 | build 按每个全屏段的最低下巴算字幕高度；截图里仍看到压嘴，就在 spec 里加 punch 前后检查 |
| 小窗跟脸走 | 人会动、脸通常不在画面正中，固定裁切会偏 | face.json 平滑后驱动小窗裁切；没有 face.json 时 build 退成居中，必须先跑 face.py |
| 全屏段不叠文字条 | 顶部文案、下方字幕、人脸三处抢注意力 | 全屏段只留 hook 和 finale；信息放到小窗段的卡片里 |
| 外文素材翻成中文重做 | 观众不会读英文原图，原图+中文字幕两头都看不清 | news / post 卡按原版式重做，表头 note 标"中文译文" |
| 原话要全 | 被折叠的帖子、被截断的引语会改变意思 | fetch_post.py 取全文；报道引用以原文为准 |
| 不来回缩放 | 每个跳切都推拉，观感晃 | 粗剪不加缩放；包装只在 0–2 处用 punch |
| 居中元素要真居中 | 估算 left 值会偏 | build 里按钮、标题都用整宽 + 文字居中 |
| 装饰图要画对 | 观众会认出画错的篮球场/图表 | court 背景按 FIBA 尺寸画；没把握的装饰宁可不画 |
| 卡片和字幕不叠 | 小窗段字幕在 y≈1268，卡片区到 y≈1150 | 卡片内容太多就拆成两张卡，别把字号压到 28px 以下 |
| 字幕纠错 | ASR 会把专名、同音字、数字写错，有时用词不准（"刺杀"实为"遇害"） | phrases.txt 逐行过一遍再 align |
| 事实核实 | 自媒体出错的代价远大于少一张卡 | 引用说清场合（演讲还是发帖）、日期；时间轴的年份逐个核对 |

## 节奏参考（竖屏口播 60–120 秒）

- 前 3 秒：hook 标题第 0 帧就在，第一句话就是钩子。
- 每 6–12 秒画面要有变化：小窗切换、新卡片、新节点、揭晓。
- 全屏段别超过 20 秒没有任何变化；实在没有可配的信息，用一次 punch。
- 揭晓（数字翻牌、盖章）对准说到那个词的时刻，配音效。
- 结尾停在最有力的一句，接互动问题卡，不要总结。
