# 演奏视频的音乐特效

**演奏者是主角，特效只是灯光师。** 好的点缀让观众觉得「这段音乐更有感觉了」，而不是「哇好多特效」。本 skill 的工作，就是让效果的出现、强弱、颜色都服从音乐和画面。

你来负责看画面、读懂音乐结构、设计效果；脚本负责节拍分析、逐帧渲染和合成。内置 4 种效果可以直接用，你也可以写新效果（见 [references/custom.md](references/custom.md)，`examples/rising_notes.py` 是一个完整的范例）。

## 怎么运行

```bash
uv run "<skill目录>/scripts/mv.py" <命令> ...      # 下文简写成 mv.py
```

依赖和 ffmpeg 会自动安装，Mac 和 Windows 命令一样。第一次先跑 `mv.py doctor`。没装 uv 的话，把安装命令告诉用户，让用户自己装：macOS 运行 `curl -LsSf https://astral.sh/uv/install.sh | sh`；Windows 在 PowerShell 里运行 `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`。

## 流程

### 1. 看画面

```bash
mv.py look "<视频>"              # 缩略图 + 画面主色
mv.py look "<视频>" --grid 20    # 带坐标网格的大图，用来确定位置
```

从图里弄清楚这几件事，后面每一步都要用：
- **不能挡的地方**：演奏者的脸、手、琴键或琴弦、谱子，以及画面里已有的文字（标题、字幕、水印）
- **空着的地方**：墙、天空、深色背景、画面边缘。效果放在这里
- 画面整体偏亮还是偏暗、偏暖还是偏冷，画面里有没有现成的强调色

### 2. 听结构

```bash
mv.py music "<视频>"             # 华尔兹 / 3 拍的歌加 --meter 3
```

输出包括：
- 速度，以及节拍稳不稳
- 哪里有音乐
- 强弱结构（安静 / 中 / 强，按时间分段）

如果用户告诉你歌的段落（前奏、主歌、副歌），就以用户说的为准，强弱结构只做参考。

### 3. 设计（最重要的一步）

**先跟用户用一两句话说清楚你的设计，再动手写方案。** 比如：「前奏只放歌名卡，主歌让边框跟着重拍轻轻呼吸，副歌加强并在两侧上方迸发粒子，结尾留白。」

设计原则：

1. **跟着段落走，要有起伏。** 安静的段落几乎不放效果，或者只放最弱的呼吸；最强的效果只留给最强的段落。至少 1/3 的时长是「安静或几乎没有效果」。一首歌从头到尾都在闪，等于没有重点。
2. **同一时间最多两种动态效果。** 边框律动加粒子已经很丰富了，再加第三种就乱。
3. **速度决定手感：**

   | 歌 | 设置 |
   |---|---|
   | 慢歌 / 抒情（<80 BPM） | `kind: "down"`（只在重拍）、`decay: 0.4`、`strength: 0.5–0.7`，像呼吸一样 |
   | 中速 | `kind: "beat"`、`decay: 0.22`（默认）、`strength: 0.8` |
   | 快歌（>130 BPM） | `kind: "down"` 或 `decay: 0.15`。每拍都闪会很累眼 |
   | 自由速度 / 钢琴独奏 / 散板 | `sync: "auto"` 会自动改成跟音符起音，`strength` 再降一点 |

4. **位置避开主角。** 粒子、飘音符的 `anchors` / `at` 放在第 1 步找到的空地方，从网格图上读坐标。绝不能盖住手、琴键和脸。竖屏视频的上下 12% 会被平台界面遮住，那里也别放东西。
5. **颜色从画面里取。** 一个主色，加白色，就够了。暖光的房间用暖色（琥珀、珊瑚、暖粉），冷色调或夜景用冷色（青、淡蓝、淡紫）。避开跟肤色相近的颜色，也别用高饱和的纯红、纯绿。画面很亮时，边框律动用深一点、饱和一点的颜色才看得出来；画面很暗时就用亮色。
6. **文字只说一次。**
   - 歌名卡在**音乐开始后**约 1 秒出现，停 5–6 秒。如果开头是空白或说话，就把 `start` 往后挪到音乐开始的地方
   - 视频本身已经有标题或片尾，就不要再加歌名卡或片尾卡
   - 片尾卡写一句简短的话就够了，比如「谢谢收听」或「下期弹 xxx」
7. **安全**：整个画面的闪烁不要超过每秒 3 次，避免引起光敏不适。
8. **音效**：默认关闭（`style.sfx: false`）。音乐视频不要加「叮」「嗖」这类音效。

### 4. 写方案

```bash
mv.py init "<视频>"      # 在视频旁边生成 <视频名>_特效方案.json，这只是起点
```

同一种效果可以出现多次，每次覆盖不同的时间段、用不同的强度。分段的层次就是靠这个做出来的：

```json
{
  "video": "童年钢琴.mp4",
  "meter": 4,
  "style": { "accent": "#E8604C", "dark": "#2A2420", "sfx": false },
  "effects": [
    { "type": "song_card", "title": "童年", "sub": "罗大佑 · 钢琴版", "start": 1.0, "dur": 5 },
    { "type": "pulse", "from": 0, "to": 27, "kind": "down", "strength": 0.55, "decay": 0.4 },
    { "type": "pulse", "from": 27, "to": 53, "strength": 1.0 },
    { "type": "sparkles", "from": 27, "to": 53, "anchors": [[120, 330], [960, 330]] },
    { "type": "custom", "file": "rising_notes.py", "class": "RisingNotes", "at": [900, 1640], "from": 27, "to": 52 }
  ],
  "output": { "mode": "burn" }
}
```

**内置效果**（所有时间都以秒为单位，坐标是原视频像素）：

| type | 作用 | 常用参数 |
|---|---|---|
| `pulse` | 画面边缘一圈光，随节拍亮起、衰减 | `from` `to` `kind`(beat/down/note) `sync` `strength`(0.3–1.5) `decay` `thickness`(默认 0.075) `color` |
| `sparkles` | 重拍时从指定点迸发星星粒子 | `from` `to` `anchors` `kind`(默认 big) `strength` `colors` |
| `song_card` | 左下角的歌名卡，带随节拍跳动的小音量条 | `title` `sub` `start` `dur` `at` |
| `end_card` | 最后几秒画面变暗，弹出一行大字 | `title` `sub` `dur` `dim` |
| `custom` | 你写的效果 | `file` `class`，以及你自己定义的参数 |

`sync`：`auto`（推荐，节拍稳就跟拍子，不稳就跟音符）/ `beats` / `onsets`。`from` / `to` 不写，就表示从音乐开始到音乐结束。

### 5. 创作新效果

内置效果不够表达这首歌时，就写一个。先想清楚**这首歌的气质**，再挑效果：

- 抒情、怀旧：飘起的音符（参考 `examples/rising_notes.py`），慢慢飘落的光点，画面暗角跟着乐句一起呼吸
- 欢快：重拍时一圈圆环从琴键附近扩散，彩色纸屑
- 有力量：低音重拍时画面边缘短暂冲击；但要克制，一首歌里最多用几次
- 安静的钢琴独奏：几乎什么都不加，只在乐句之间加一点光晕，「少」就是设计

把范例复制到视频旁边，改成你要的样子，在方案里用 `custom` 引用。可用的音乐接口（`ctx.music.hits` / `envelope` / `energy`）和写法见 [references/custom.md](references/custom.md)。

### 6. 检查和出片

```bash
mv.py check "<视频>"            # 校验，并试画每个效果；自定义代码有错会在这里报出来
mv.py still "<视频>" --at 30     # 几帧成品效果图
mv.py render "<视频>"            # 出片，同时出 <视频名>_检查图.jpg
```

**检查清单**：
1. 有没有挡住手、琴键、脸、画面里已有的字？
2. 颜色跟画面协调吗？效果在亮画面上看得出来吗？会不会太跳？
3. 安静段落是不是真的安静？最强的效果是不是落在最强的段落？
4. **节奏感只能看动态**：静帧图看不出效果是否卡在拍子上。出片后一定要请用户看一遍成片，问他「跟拍子吗？会不会太多？」，然后按反馈调整 `strength`、`decay`、`kind`、`from`/`to`

| mode | 产出 | 给谁 |
|---|---|---|
| `burn`（默认） | `<视频名>_特效版.mp4`，可以直接发布 | 所有人，剪映用户只能用这个 |
| `overlay` | `<视频名>_叠加层.mov`，ProRes 4444 带透明通道 | 用 Final Cut / Premiere / 达芬奇的人，文件很大 |

改了方案再 render，只会重画改动过的效果。

## 交付时跟用户说

- 成片路径
- 你的设计：一两句话，说清楚哪段放了什么、为什么这样放
- 他可以怎么调：哪段要更强或更弱、换颜色、去掉某个效果、加一个新点子，跟你说一声就行
